# 🤖 Crawl4AI 爬蟲實戰案例

> 本頁所有案例都是 **🤖 CRAWL4AI PROJECT**。若要學習瀏覽器操作與自動化，請前往 [🎭 Playwright 12 個實戰專案](../playwright/實戰專案/README.md)。

以下案例由淺入深，展示如何用 Crawl4AI 完成結構化資料擷取、動態網頁處理、批次爬取與 GUI 監控。

---

## 📈 實戰專案列表

### 1. 台灣銀行牌告匯率（入門）
- **Framework**: 🤖 **Crawl4AI**
- **專案路徑**: [01_台灣銀行牌告匯率](../crawl4AI/實戰專案/01_台灣銀行牌告匯率/)
- **類型**: 靜態網頁爬蟲
- **技術要點**: 
  - CSS Schema 結構化資料擷取
  - 排程與定時更新機制
- **適合對象**: 剛完成基礎教學、想體驗第一個完整爬蟲專案的初學者。
- **難度**: ⭐⭐ 初級

### 2. 台灣即時股票資訊（中級）
- **Framework**: 🤖 **Crawl4AI**
- **專案路徑**: [02_台灣即時股票資訊](../crawl4AI/實戰專案/02_台灣即時股票資訊/)
- **類型**: 動態網頁爬蟲
- **技術要點**:
  - JavaScript 動態渲染頁面處理
  - 動態載入內容的等待與抓取
  - 自訂屬性選擇器與精準定位
- **適合對象**: 已經理解靜態網頁抓取，想挑戰動態 JavaScript 渲染網頁的學習者。
- **難度**: ⭐⭐⭐⭐ 中級

### 3. 股票批次爬取 - GUI 桌面版（高級）
- **Framework**: 🤖 **Crawl4AI**
- **專案路徑**: [03_股票批次爬取_GUI](../crawl4AI/實戰專案/03_股票批次爬取_GUI/)
- **類型**: 功能完整的爬蟲桌面工具（AI 輔助開發）
- **技術要點**:
  - 雙模式運行（命令列 CLI + GUI 介面）
  - 非同步批次爬取與並發控制
  - 爬取進度即時顯示
  - 股票搜尋與批量全選功能
- **適合對象**: 想要學習如何將爬蟲核心與使用者介面（Tkinter）結合，以及處理批次任務的進階學習者。
- **難度**: ⭐⭐⭐⭐⭐ 高級
- > 💡 **提示**：本專案是 AI 輔助開發的完整專案，內含需求文件（`PRD.md`）與詳細設計說明，非常適合學習如何利用 AI 協同開發實用工具。

### 4. 股票即時監控 - GUI 桌面版（高級）
- **Framework**: 🤖 **Crawl4AI**
- **專案路徑**: [04_股票即時監控_GUI](../crawl4AI/實戰專案/04_股票即時監控_GUI/)
- **類型**: 完整即時資料桌面應用程式（AI 輔助開發）
- **技術要點**:
  - Tkinter GUI 設計
  - 多執行緒（Multi-threading）與非同步背景監控
  - 自動定時更新機制
  - 數據視覺化呈現（如紅漲綠跌顏色標記）與即時搜尋
- **適合對象**: 想學習更複雜的多執行緒程式設計、GUI 介面即時更新與監控系統架構的進階學習者。
- **難度**: ⭐⭐⭐⭐⭐ 高級
- > 💡 **提示**：建議先閱讀與練習 **專案 3（批次爬取版）**，再進行本專案（即時監控版）的學習。

## 🛠️ 開發流程建議（AI 輔助開發）
專案 3 與 4 均包含了完整的需求文件（`PRD.md`），展示了現代軟體開發中如何利用 AI 輔助從需求分析、架構設計到程式碼生成的完整工作流程。建議您在閱讀程式碼之餘，也花時間閱讀其需求文檔，學習如何對 AI 進行精準提問與任務拆解。
